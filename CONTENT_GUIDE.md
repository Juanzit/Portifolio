# Guia de Conteúdo

- Nunca inventar cargos, empresas, métricas, links, repositórios ou identificadores; usar `[A CONFIRMAR]` quando o dado não existir.
- Pesquisa de bioacústica: sempre "Cenário A (Controle)" e "Cenário B (Proposto)".
- Textos em português do Brasil (`lang="pt-BR"`), tom técnico e editorial.
- Simuladores/laboratórios devem informar que rodam localmente no navegador, sem banco de dados real nem API paga.
- Conteúdo de exemplo no `/design-system` é ilustrativo e não representa dados reais do autor.
